# 🏭 Software Factory

## Overview

Agent harness that can build software using AI agents, reapeatadly with minimum human intervention.

## The autonomy ladder

/| Lavel | Shorthand | Humban role | AI role |
| ------------- | -------------- | -------------- | -------------- |
| 0 | Spicy Autocomplete | Writes Code | Search/Suggestions |
| 1 | Coding Intern | Delegates small tasks| Boilerplate, test, docs |
